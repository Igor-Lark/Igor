# Boat Content Factory

Внутренний инструмент для подготовки материалов сайта [boat-sochi.ru](https://boat-sochi.ru/). Он хранит направления, страницы, исследования, тексты, рекламу и креативы. Публикация на сайт и действия в рекламном кабинете остаются за человеком.

## Стек

Приложение — один локальный процесс Node.js.

- TypeScript и Next.js: интерфейс и HTTP API.
- SQLite (`better-sqlite3`): постоянное хранение, файл копируется целиком.
- Исполнитель задач в том же процессе, с ограничением параллелизма. Отдельная очередь и Redis не нужны одному локальному пользователю.
- Cheerio: разбор уже полученного HTML.
- OpenAI-совместимый API и необязательный поиск Tavily. Без ключей соответствующие шаги завершаются явной ошибкой и не подменяются выдуманным результатом.

Почему так: репозиторий был пустым, продукт один и локальный, а данные и история должны переживать перезапуск. Микросервисы, отдельная очередь и векторная база здесь ничего не ускоряют и добавляют точки отказа.

Подробности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка

Нужен Node.js 22.

```bash
npm install
cp .env.example .env
```

Ключи в `.env` необязательны для запуска. Пока их нет:

- получение страниц boat-sochi.ru, правила SEO, промпт из полей, загрузка изображений и технические свойства файла работают;
- веб-поиск, генерация текстов и экспертные оценки изображений сообщают, что сервис не настроен.

Переменные:

| Переменная | Назначение |
| --- | --- |
| `BCF_DATA_DIR` | Каталог базы, снимков и загрузок. По умолчанию `./data`. |
| `BCF_MAX_CONCURRENT_TASKS` | Сколько задач выполнять сразу. По умолчанию 2. |
| `BCF_MAX_EXTERNAL_CALLS` | Общий предел одновременных внешних HTTP-вызовов. |
| `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL` | Текстовая модель. |
| `OPENAI_VISION_MODEL` | Модель со зрением. Пустое значение отключает оценки креативов. |
| `TAVILY_API_KEY` | Веб-поиск. Без него исследование идёт только по указанным URL. |

Ключи не записываются в базу, интерфейс и экспортируемые файлы.

## Запуск

```bash
npm run dev
```

Интерфейс открывается на `http://127.0.0.1:3000`. Сервер специально слушает только localhost.

Для обычного запуска после сборки:

```bash
npm run build
npm start
```

При первом запуске пустая база получает сайт boat-sochi.ru, три направления и неподтверждённые условия со страницы `https://boat-sochi.ru/llms.txt` (на ней указано «актуально 15.10.2026»). Это не результаты задач и не подтверждение цен. Снимки страниц сами не скачиваются.

## База и резервная копия

Миграции лежат в `migrations/` и применяются при открытии базы. Отдельная команда миграции не нужна.

```bash
npm run backup
```

Команда создаёт каталог `data/backups/<дата>/` с файлом SQLite, `uploads/` и `snapshots/`. Восстановление: остановить приложение и заменить `data/boat-content-factory.sqlite`, `data/uploads` и `data/snapshots` содержимым копии.

Удаления задач и версий в интерфейсе нет, чтобы история не стиралась случайно.

## Что сознательно не входит в эту версию

- публикация и правка сайта, доступ к CMS;
- создание кампаний, объявлений, ставок и бюджетов в Яндекс Директе;
- загрузка креативов в рекламный кабинет;
- CRM, роли нескольких пользователей и несколько сайтов;
- статистика кабинета, прогноз CTR и конверсий;
- собственная генерация изображений и векторный поиск.

Согласование материала меняет только статус внутри приложения.
