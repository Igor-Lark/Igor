## Куда вставить в Tilda

1. Откройте страницу **main** в редакторе Tilda
2. **Настройки страницы** → вкладка **SEO**
3. Заполните поля:
   - **Заголовок** — текст из раздела «Заголовок»
   - **Описание** — текст из раздела «Описание»
   - **Ключевые слова** — текст из раздела «Ключевые слова»
4. **Настройки страницы** → **Дополнительно** → **HTML-код внутри `<head>`**
5. Вставьте содержимое файла [`main-microdata.html`](main-microdata.html) (без комментариев)
6. **Опубликуйте** сайт
