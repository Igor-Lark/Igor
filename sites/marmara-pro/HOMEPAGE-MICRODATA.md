# Микроразметка главной marmara-pro.ru

Файл для копипаста: [homepage-microdata.html](./homepage-microdata.html)

**Страница:** только `https://marmara-pro.ru/` (не `/main`, не `/termo`).

**Тильда:** Настройки страницы → Дополнительно → HTML-код внутри `<head>`. Старый JSON-LD удалить, вставить один `<script type="application/ld+json">`, опубликовать.

**Проверка:** [Яндекс.Микроразметка](https://webmaster.yandex.ru/tools/microtest/) и [validator.schema.org](https://validator.schema.org/).

Типы: `WebPage`, `WebSite`, `Organization` + `LocalBusiness` + `HomeAndConstructionBusiness`, `FAQPage` (11 вопросов с живой главной).
