# Как отдавать статистику агентам РК (vitaminki21)

Агенты **не входят** в Яндекс Директ. Логин и пароль **не писать** ни в какой чат.

**Сейчас:** API не подключено. Агент видит кампанию, только если ты принесёшь **CSV + скрины** в чат **нужного** агента.

**Через API (можно позже):** не пароль, а OAuth-токен Яндекса. Токен — в секрет окружения агента, не в git и не в переписку. Тогда скрипт сам снимет отчёт за неделю (запросы, группы, дни) по номеру РК. Скрины стратегии/целей всё равно полезны: часть настроек в отчёте не видно.

Этот чат «Анализ boat рекламы» — архив. Анализировать живую РК здесь не надо: контекст сжимается, агент путает продукты.

## 2. Как открыть агента

1. Зайди по ссылке из таблицы (браузер или Cursor → Agents).
2. Пиши в этот же тред. Не плоди второго «Агента Сириус».
3. Первым делом в сообщении укажи: **код РК, номер кампании, период Пн–Вс, что прикладываешь**.
4. Файлы перетащи в чат (CSV, PNG/JPG). Можно несколько файлов в одном сообщении.
5. Напиши задачу одной фразой, например: «разбор недели 10–16.08, минусы и не трогать CPA».

Если ссылка не открывается — новый облачный агент на репозиторий **Igor-Lark/Igor**, первым сообщением вставь нужный `*_agent_start.md` или «прими handoff …».

## 3. Что выгрузить из Директа

Зайди сам: https://direct.yandex.ru → аккаунт **vitaminki21**.  
Открывай кампанию **по номеру**, не по похожему названию.

Период всегда **календарная неделя Пн–Вс** (обучение Директа считается так).  
Для сравнения SR ↔ MP — **одна и та же** неделя на обе РК.

### 3.1. CSV (главное для анализа)

В кампании: **Статистика → Мастер отчётов** (или «Отчёты»).

Сделай **три выгрузки** этой же РК за ту же неделю (или одну широкую, если мастер позволяет несколько срезов):

1. **Поисковые запросы** — обязательно. Без этого минусы и мусор автотаргета не видны.
2. **По группам** — какие группы жрут бюджет, какие на паузе.
3. **По дням** — провал/всплеск внутри недели.

Столбцы минимум: показы, клики, CTR, расход, ср. цена клика, конверсии, цена достижения цели, отказы (если есть).  
Площадки если видно: Поиск / РСЯ / Карты.

Скачивай **CSV**. Имя подпиши сам, если Директ дал кашу:

`SR_704503370_zaprosy_2026-08-10_16.csv`  
`MP_712465896_gruppy_2026-08-10_16.csv`

Не склеивай две РК в один файл.

### 3.2. Скрины (то, чего нет в CSV)

Снимай так, чтобы читались цифры и номер РК в шапке.

**Обязательные (каждая неделя):**

1. Шапка кампании: название, **номер**, статус, недельный бюджет.
2. **Стратегия**: тип (макс. конверсий / оплата за конверсии и т.д.), бюджет, цены целей.
3. **Цели**: телефон, Telegram, MAX, профиль организации — цена каждой.
4. **Места показа**: РСЯ вкл/выкл, Карты, галерея услуг / список организаций.

**По ситуации:**

5. Список групп: активна / пауза (особенно «Закат», «рыбалка», «Аренда яхт Сириус»).
6. Автотаргет: альтернативные и сопутствующие — вкл/выкл.
7. Топ запросов на экране, если CSV запросов не выгрузился.
8. Объявления / быстрые ссылки, если просишь разобрать тексты.

Не надо: пароль, полный кабинет всех РК одним скрином без номеров, скрин «красивой» сводки без запросов.

## 4. Что написать агенту вместе с файлами

Скопируй и подставь:

```
РК: SR 704503370 (или MP 712465896 / ZK / TG …)
Период: Пн–Вс 10.08–16.08.2026
Файлы: CSV запросов, CSV групп, скрины стратегии и целей.
Задача: разбор недели. Минусы предложи списком. Стратегию и CPA без моего «да» не менять.
```

Для сверки (конфликт SR ↔ MP):

```
Сверка SR 704503370 и MP 712465896
Одинаковая неделя: Пн–Вс …
Вложения: CSV+скрины обеих РК.
Нужен вердикт: мешают / не мешают / риск и какие минусы с обеих сторон.
```

---

## 5. Чего агент не сделает без тебя

- Не увидит свежие цифры, пока нет CSV/скринов этой недели.
- Не зайдёт в Директ и не нажмёт «пауза» / «изменить CPA». Ты подтверждаешь, ты кликаешь в кабинете.
- Не считает «распечатал»: Word уходит в очередь `inbox/`, печатает мост на ПК.

Не меняй **две** стратегии или CPA в один день на соседних РК (SR и MP).

---

## 6. Если подключать API

1. На https://oauth.yandex.ru создай приложение с доступом к **API Директа**.
2. Под аккаунтом **vitaminki21** выпусти токен (ссылка авторизации приложения).
3. Токен положи в секрет окружения облачного агента (имя вроде `YANDEX_DIRECT_TOKEN`). В чат не вставляй.
4. Напиши в этот или портфельный чат: «токен в секрете, пиши клиент». Появятся `cursor/direct_report.py` и вызов по номеру РК / неделе Пн–Вс.

Пока секрета нет — только CSV + скрины, как в разделах 3–4.

---

## 7. После ответа агента

- Минусы и паузы групп — внеси в Директ сам, напиши агенту «сделал».
- Word-анализ: агент кладёт в `inbox/` и пушит свою ветку; на ПК watcher печатает сам.
- Не пересылай тот же пакет в этот родительский чат «на всякий случай».
