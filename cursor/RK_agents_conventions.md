Дата: 28.08.2026  
Источник: пользователь → агенты РК (печать 23.08 GU; промпт Leonardo 28.08 ZK).

## Печать — не нужна

С 23.08.2026 печать **не нужна**. Правило для всех агентов РК (SR, MP, ZK, GP, TG, RB, GU, сверка, портфель).

- Word по-прежнему класть в `cursor/` и давать ссылку на скачивание в чат
- **Не** вызывать `python3 cursor/queue_print.py`
- **Не** класть `.docx` в `inbox/`
- Не писать «в очереди печати» и не просить распечатать

## Минус-слова — только столбиком

Когда агент выдаёт минус-слова или минус-фразы (в чат, в Word, в план действий):

- **по одной фразе на строку**
- без запятых и без склейки пробелами в одну строку
- так, чтобы сразу копировать в поле минус-слов Директа

Правильно:

```
скайпарк
подкова
сириус рент
наталья
```

Неправильно: `скайпарк  подкова  сириус рент  наталья`

То же в Word: список маркерами или таблица «одна фраза — одна строка», не абзац.

Агенты: Tigger, Сириус, Морские прогулки, Групповые прогулки, Закат на море, Групповая рыбалка, Галерея услуг, сверка РК, портфель РК.

## Leonardo / Nano Banana — промпт одним блоком

Когда агент пишет промпт для Leonardo, Nano Banana или другой генерации картинок:

- **Сам промпт и negative — один блок** (один code fence), чтобы копировать разом
- Не разносить Prompt и Negative в два поля чата
- Внутри блока негатив с новой строки, с меткой `Negative:`

Правильно:

```
Ultra-realistic photograph, golden hour, couple on a small motor yacht at sunset, Black Sea. No text, no logos.

Negative: cartoon, CGI, dolphins, crowded tourist boat, text, watermark, logo
```

Неправильно: два отдельных блока «Prompt» и «Negative».

Агенты: Tigger, Сириус, Морские прогулки, Групповые прогулки, Закат на море, Групповая рыбалка, Галерея услуг, сверка РК, портфель РК.
