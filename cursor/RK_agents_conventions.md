# Общие правила агентов РК boat-sochi

Дата: 16.08.2026  
Источник: пользователь → агент Tigger, распространить на все РК.

## Минус-слова — только столбиком

Когда агент выдаёт минус-слова или минус-фразы (в чат, в Word, в план действий):

- **по одной фразе на строку**
- без запятых и без склейки пробелами в одну строку
- так, чтобы сразу копировать в поле минус-слов Директа

Правильно:

```
скайпарк
подкова
сириус рент
наталья
```

Неправильно: `скайпарк  подкова  сириус рент  наталья`

То же в печатных Word: список маркерами или таблица «одна фраза — одна строка», не абзац.

Агенты: Tigger, Сириус, Морские прогулки, Групповые прогулки, Закат на море, Групповая рыбалка, сверка РК, портфель РК.
