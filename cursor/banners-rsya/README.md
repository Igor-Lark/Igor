# HTML5-баннеры РСЯ для Сириуса (boat-sochi)

## Варианты текстов (из конверсионных объявлений)

1. **v1-progulki** — «Морские прогулки в Сириусе / Аренда каютного катера» (объявления 17381764710, 17676642893)
2. **v2-price** — «Аренда яхты в Сириусе / от 15 000 ₽ за 2 часа» (коммерческая группа)
3. **v3-zakat** — «Яхта на закат в море / Имеретинский порт» (группа «Закат»)
4. **v4-delfiny** — «Утром к дельфинам / Адлер·Сириус» (группа дельфинов)

## Размеры
- 300×250 — универсальный
- 240×400 — вертикальный
- 728×90 — лидерборд
- 320×100 — мобильный

## Как загрузить в Директ
В каждой папке варианта лежит ZIP `vN_*_WxH.zip` — загружайте его как HTML5-баннер.
Либо откройте `preview.html` локально для просмотра всех макетов.

Ссылка по умолчанию: https://boat-sochi.ru (в РСЯ сработает clickTAG кампании).
