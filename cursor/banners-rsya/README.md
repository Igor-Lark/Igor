# HTML5-баннеры РСЯ (обновление)

## Анимация
Текст и кнопка появляются **справа по очереди** с задержкой **0,5 с**:
1. локация (0 с)
2. заголовок (+0,5 с)
3. подзаголовок (+1,0 с)
4. кнопка (+1,5 с) + пульс
