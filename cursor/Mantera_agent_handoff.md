## 2. Что сделать, когда придёт пакет

1. Записать в память: номер, имя, продукт, цена, URL, телефон, цели, места показа, автотаргет, галерея вкл/выкл.
2. Сверить с соседями (см. §3): ключи, минусы, посадка, оффер, телефон.
3. Выдать вердикт: **ок / риск / конфликт** + минусы **столбиком**.
4. Не менять CPA/бюджет этой и соседних РК без явного «да».
5. Обновить этот файл и `Mantera_campaign_memory.md`.

Как писать задачу вместе с файлами:

```

Период: Пн–Вс …
Файлы: CSV запросов, CSV групп, скрины стратегии и целей.
Задача: разбор недели. Минусы столбиком. Стратегию и CPA без моего «да» не менять.
```

- Один чат = одна РК. Выгрузки Сириуса / групповых сюда не разбирать как «свою» кампанию.
- Минус-слова — **по одной фразе на строку**, без склейки в абзац (`cursor/RK_agents_conventions.md`).
- Печать не нужна. Word в `cursor/`, ссылка в чат.
- Не входить в Директ, не просить пароль.
- Не менять две стратегии/CPA соседних РК в один день.
- Не писать в объявлениях чужой телефон (Олег vs Наталья), пока не ясно, чей продукт.
- Информация на сайте — не оферта. Дельфинов не гарантировать.
