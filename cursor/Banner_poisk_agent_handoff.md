## 1. Что это за формат

| | |
|--|--|
| Место | Справа от выдачи Яндекса (десктоп). На странице **один** баннер |
| Мобильные | **Нет** |
| Файл | JPG / PNG / **GIF**. **Не HTML5 ZIP** |
| Размер | **240×400**, максимум **120 КБ** |
| В объявлении | Один креатив + ссылка. Заголовков, быстрых ссылок и уточнений **нет** |
| Оплата | За клик |
| Стратегии | **Оптимизация кликов** или ручные ставки. Не ЕПК «макс. конверсий» |
| Автотаргет | Обычно **нет**. Не включать, если поле появится |
| Цель в мастере | «Заметность на Поиске Яндекса» / «Контекстный баннер в Поиске» |

Это поддержка текстовой РК на десктопе, не замена. CPC обычно выше, чем у текста.

Правило «8 быстрых ссылок» на этот формат **не распространяется** — в объявлении некуда их ставить. На текстовой GP по-прежнему 8 ссылок.

## 4. Группа и ключи

Группа: **G1 · Билет парус 1800**.

Ключи — **фразовое совпадение (кавычки)**. Только групповой интент.  
**Не** ставить широкие «морские прогулки», «прогулки на яхте сочи», «яхта сочи аренда» — это **SR**.

```
"групповая прогулка на яхте сочи"
"групповая прогулка на яхте сириус"
"групповые прогулки на яхте сочи"
"билет на яхту сочи"
"билет на яхту сириус"
"прогулка на яхте за человека"
"прогулка на яхте за человека сочи"
"прогулки под парусом сириус"
"прогулка под парусом сочи"
"парусная прогулка сириус"
"парусная прогулка сочи"
"место на яхте сочи"
"групповая морская прогулка сириус"
"яхта сириус групповая"
```

**НЕ минусовать:** группа, билет, за человека, 1800, парус, парусная, до 11, расписание, купание.

Минусы — **столбиком**, см. Word / раздел 5 генератора.

## 6. Антиканнибализация

| РК | Связь с BP-GP |
|----|----------------|
| **GP** текстовая | Тот же продукт и посадка. Баннер — правый блок десктопа. Бюджеты **разные**. Ключи зеркалить узкие. |
| **SR** | Минус аренда/прокат/катер на час/целиком. Не брать «морские прогулки» и «яхта сочи аренда». |
| **ZK** | Не крутить «для двоих / судно целиком вечером». Слот 18:00 на баннере = билет 2 500, не аренда. |
| **RB** | Минус рыбалка. Баннер рыбалки — отдельная РК позже. |
| **TG / AX** | Минус vip / tigger / алексум. |
| **GU** | Галерея не этот формат. Не включать галерею в текстовых РК. |
| **MP** | Архив / не мешать. Посадка не главная. |
