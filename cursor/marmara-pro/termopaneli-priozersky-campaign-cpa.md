## Предварительные условия (обязательно до запуска CPA)

1. **Яндекс Метрика** на `marmara-pro.ru` (Tilda: счётчик в настройках сайта, на всех страницах).
2. **Связка Метрика ↔ Директ:** Директ → Настройки → **Метрика** → счётчик сайта подключён.
3. **Цели** (отдельные, с понятными названиями для отчётов):

| Цель | Как настроить | Роль в кампании |
|---|---|---|
| **Заявка с сайта** | JavaScript-событие или «Отправка формы» Tilda на `/termo` и общих формах | Основная конверсия для CPA |
| **Клик по телефону** | Цель «Клик по номеру телефона» или JS на `tel:+79217457755` | Доп. конверсия (звонки с мобильных) |

4. **Проверка:** в Метрике → «Отчёты» / «Конверсии» — цели срабатывают при тестовой заявке и тестовом клике по телефону.
5. **Атрибуция:** для старта оставьте **«Последний значимый переход»** или рекомендуемую Директом модель; **не меняйте** модель и состав целей первые 1–2 недели после запуска (сбрасывает обучение).

**Оплата за конверсии:** списание за конверсии, произошедшие **в течение 21 дня** после клика по объявлению ([справка Директа](https://yandex.com/support/direct/ru/strategies/average-cpa-conversions)).

## Стратегия «Максимум конверсий» + оплата за конверсии

### Шаги в интерфейсе

1. Создать кампанию → **Поиск** → **Режим эксперта**.
2. Название: `КлинкерПрофи — термопанели, Приозерский район (Поиск, CPA)`.
3. **Места показа:** только **Поиск** (без РСЯ), если доступен выбор на уровне кампании.
4. Раздел **Стратегия:**
   - Стратегия: **Максимум конверсий**
   - Модель оплаты: **За конверсии** (не «за клики»)
   - Бюджет: **на неделю** (не «без ограничений»)
   - Ограничение: **Цена конверсии**
5. **Цели:** выбрать одну или обе цели из таблицы выше; для **каждой** указать **максимальную цену конверсии** (лимит, выше которого система не должна закупать конверсии в среднем по кампании).
6. Сохранить кампанию.

### Рекомендуемые CPA и бюджет (стартовые, скорректировать по факту)

Для ниши «термопанели / B2C–малый B2B», узкое гео:

| Цель | Стартовая цена конверсии (макс.) | Комментарий |
|---|---|---|
| Заявка с сайта | **1 200–2 000 ₽** | Основной KPI; если мало показов — поднять на 15–20 % через неделю |
| Клик по телефону | **400–800 ₽** | Часто дешевле заявки; не дублируйте одного клиента в отчётах без сквозной аналитики |

**Недельный бюджет** (правило Директа: ≥ **10 ×** цена конверсии):

| Сценарий | CPA заявки | Мин. недельный бюджет |
|---|---|---|
| Консервативный | 1 500 ₽ | **15 000 ₽/нед** (~2 150 ₽/день) |
| Рабочий | 1 200 ₽ | **12 000 ₽/нед** |
| Только заявка, агрессивный тест | 2 000 ₽ | **20 000 ₽/нед** |

Если выбраны **две цели**, недельного бюджета должно хватать минимум на **10 конверсий в сумме** по кампании в неделю — иначе алгоритм «голодает» и режет показы.

### Если конверсий мало (< ~10 в неделю по кампании)

1. **Этап 0 (1–3 недели):** та же кампания и гео, стратегия **«Максимум конверсий»**, но модель оплаты **за клики** + недельный бюджет 8 000–12 000 ₽. Алгоритм учится на целях, вы платите за клики.
2. После стабильных конверсий в Метрике (UTM `termopaneli_priozersk_cpa_search`) — переключить на **оплату за конверсии** с CPA из таблицы.
3. Альтернатива: временно расширить гео до **Ленобласти** с **−100 %** ставки вне Приозерского района (сложнее в эксперте; проще держать узкое гео и терпеть малый объём).

**Не менять** каждые 2–3 дня: цели, CPA, атрибуцию, модель оплаты — это перезапускает обучение.

## Геотargeting

**Регион показа кампании:** Приозерский район, Ленинградская область.

**Корректировки ставок по НП (+15…+35 %)** — опционально, стратегия CPA сама повышает ставки на конверсионную аудиторию; имеет смысл только если в интерфейсе остаётся ручная надстройка:

| Населённый пункт |
|---|
| Приозерск |
| Сосново |
| Кузнечное |
| Мельниково |
| Лесогорский |
| Ромашки |
| Синявино |

**Мобильные:** +10…+15 % (звонки и формы с телефона).

Производство — **г. Выборг**. В текстах: «производство в Ленобласти», «доставка по области»; **не** обещать бесплатную доставку в Приозерский район (в FAQ бесплатная доставка — для Выборгского района).

## Пошаговый запуск в Директе

1. Выполнить блок **«Предварительные условия»**.
2. **Создать кампанию** (Поиск, эксперт), название и гео — см. сводку.
3. **Стратегия:** Максимум конверсий → за конверсии → недельный бюджет → CPA по целям.
4. **URL-параметры** кампании — UTM из сводки.
5. **Группа** «Приозерский район» → импорт ключей и объявлений из CPA-CSV.
6. **Минус-слова** на кампании.
7. **Модерация** → после одобрения не трогать стратегию **7–14 дней**.
8. **Еженедельно:** Директ → «Поисковые запросы» → минус-слова; Метрика → цели по UTM `termopaneli_priozersk_cpa_search`.
