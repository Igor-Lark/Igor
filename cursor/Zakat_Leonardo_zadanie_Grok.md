# Задание боту Grok: промпты Leonardo для креативов РК «Закат на море»

Скопируй блок ниже целиком и вставь Grok первым сообщением.

Ты — арт-директор performance-креативов. Напиши **промпты для Leonardo.ai** (модель Phoenix / photorealistic) под рекламу Яндекс Директ.

## Продукт (не выдумывай другой)

РК **«Закат на море»**, Поиск, boat-sochi.ru, Сириус / Имеретинский порт (Сочи–Адлер).  
Продаём **судно целиком с капитаном на закат 18:00–20:00**, обычно **от 2 часов**. Пары и своя компания, ЦА **25–44**.  
Это **не** групповой билет 2 500 ₽, **не** «за человека», **не** утро к дельфинам, **не** яхта Tigger / Azimut / Алексум. Конкретную модель яхты **не называть и не рисовать как суперъяхту 20+ метров**. Флот: белый моторный катер / небольшая моторная яхта 8–12 м, реалистичный Сочи, не Дубай и не Мальдивы.

Оффер в тексте объявлений (на картинке текста **нет**): «для двоих», «судно целиком», мало катеров вечером, панорама моря / Олимпийского парка с воды.

## Задача

Дай **8 промптов** (English, copy-paste в Leonardo) + короткий **negative** на каждый.

Сцены (по одному промпту):
1. Пара 30–35 на палубе, закат, смотрят на горизонт (главный романтический кадр).
2. Та же пара, бокал / тост, без дешёвой «пены шампанского».
3. Катер целиком в кадре с воды, золотой час, берег Сириуса / Имеретинки узнаваемый, но без логотипов.
4. Женщина на носу / флайбридже, ветер, закат — не сток «инфлюенсер».
5. Своя компания 4 человека (не толпа, не мальчишник), спокойный вечер на палубе.
6. Силуэт катера и кильватер на розовом небе, без людей.
7. Вид с палубы на закат и воду, руки пары на поручне — без лиц крупно.
8. Причал вечером, мало судов, катер ждёт — ощущение «бронируйте заранее».

## Жёсткие правила Leonardo

- Только **фотореализм**, full-frame, 35mm, golden hour, natural skin. Не CGI, не иллюстрация, не аниме.
- **No text, no logos, no watermarks, no Cyrillic, no prices.**
- Нет дельфинов, нет толпы на групповой яхте, нет банана/парасейла, нет аквапарка, нет «билетной» очереди.
- Нет знаменитостей, нет голых тел, нет сексуализации.
- Вода — Чёрное море вечером, не тропики.
- Катер/яхта **целиком = private**, не 30 туристов.
- Для каждого промпта укажи: **aspect** `3:4` (сторис/РСЯ 240×400), `1:1` (квадрат), `16:9` (горизонт). Один и тот же промпт, три кадра.
- Длина промпта: 80–160 слов. Сначала subject, потом setting, light, camera, mood.
- Negative общим блоком + если сцене нужно своё — добавь.

## Формат ответа

Для каждой сцены:
- Название RU (3–6 слов)
- Зачем в РК (1 строка)
- **Один блок** copy-paste (prompt и negative вместе, негатив с новой строки `Negative:`)
- Aspects: 3:4 / 1:1 / 16:9

Пример блока:

```
Ultra-realistic photograph, ... Black Sea sunset ... No text, no logos.
Negative: cartoon, CGI, dolphins, crowded tourist boat, text, watermark
```

Не разносить Prompt и Negative в два поля.

В конце: 5 идей, чего **не** генерировать для этой РК (чтобы не слиться с дельфинами и групповым билетом).

Пиши по-русски только названия и «зачем». Сами промпты — на английском, готовые к вставке в Leonardo.
