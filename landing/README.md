# Новый год на яхте в Сириусе 2027

Отдельный HTML по макету Figma (`Boat`, кадр 1440×3772). Мобильной версии в файле не было — собрана адаптивно.

## Как открыть

Откройте `index.html` в браузере или из папки:

```bash
cd landing
python3 -m http.server 8080
```

Страница: http://localhost:8080/

## Что внутри

- Герой, блок про каникулы, карточки «Сириус» и «Лилу», гарантии, «С новым годом»
- Кнопки «Забронировать / Заказать» открывают форму
- На телефоне снизу закреплены «Позвонить» и «Забронировать»
