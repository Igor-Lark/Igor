## 2. Методы крепления термопанелей с клинкером

### 2.1. Прямое крепление на стену (основной «сухой» метод)

1. **Основание:** прочное, сухое; перепады на участке до ~10 мм на 3 м² допустимы при точной подгонке; слабую штукатурку снять.
2. **Стартовый профиль** по периметру (цоколь, горизонт) — защита от смещения и влаги снизу.
3. **Клей-пена** (полиуретановая, для пенополистирола/фасадов) — полосы по периметру панели и через 25–30 см; не «сплошной мат», чтобы не было мостиков холода.
4. **Механическое крепление:** дюбель-гвозди / тарельчатые дюбели через **закладные** в панели (не только в клей). Количество — см. расчёт.
5. **Стыковка «шип–паз»** между панелями + при необходимости тонкий шов пены в вертикальных стыках панелей.
6. **Затирка** декоративных швов **клинкера** (не путать со стыком панелей) — цементная фасадная смесь.

### 2.2. Обрешётка (подсистема)

- При **сильной неровности** стены, **каркасном доме**, необходимости **вентзазора** или дополнительного слоя утеплителя.
- Кронштейны → направляющие → панели на клей-пену + саморезы/дюбели в обрешётку.
- В СПб/ЛО часто упоминают при **дереве**, **СИП**, старых фасадах с перепадом.

### 2.3. Подбор дюбелей по основанию

| Основание | Тип крепежа |
|-----------|-------------|
| Кирпич, бетон | Тарельчатый дюбель / дюбель-гвоздь, анкер |
| Газобетон | Дюбель для газобетона (распор с низким давлением) |
| Пеноблок / керамоблок | Упорный / специализированный дюбель |
| Дерево | Саморез по дереву в обрешётку |

**Длина:** толщина панели + 40–60 мм зацепления в несущем слое (по инструкции производителя панели и дюбеля).

## 3. Особенности монтажа в Ленинградской области

- **Климат:** высокая **влажность**, ветер, **много циклов оттаивания**; фасад — барьер от дождя и мороза.
- **Толщина утеплителя** для **постоянного проживания:** чаще **60–100 мм** (ППС 25 кг/м³ или ППУ — по проекту); у **Финского залива** и открытых участков ближе к верхней границе.
- **Паропроницаемость:** не создавать «пирог» с полностью закрытым паром наружу без расчёта; при сомнении — менеджер / проектировщик.
- **Затирка швов:** только при **+5 °C … +30 °C** (летние смеси); при **+5…+10 °C** — «зимние» модификации затирки. Зимой панели ставят, швы часто **весной**.
- **Монтаж панелей зимой:** до **−10…−15 °C** — **зимняя** клей-пена; баллоны **+18…+22 °C** перед работой.
- **Узлы:** отливы, капельники, герметизация примыканий к окнам; после зимы — осмотр швов.
- **Ветровые нагрузки:** механическое крепление обязательно, не только пена.

## 4. Технология малых производств (как у КлинкерПрофи по масштабу)

Типовая схема **не гигантского завода**:

1. **Пресс-форма** (сталь/алюминий): ячейки под клинкер, паз–гребень, закладные под дюбель.
2. **Антиадгезионная смазка** формы.
3. **Укладка клинкерной плитки** в матрицу; швы между плитками иногда **засыпают кварцевым песком** (защита ППУ от УФ в шве до затирки на объекте).
4. **Заливка:** **ППС** (вспенивание в форме) или **ППУ** (компоненты A+B — машина высокого давления или, на малых линиях, дозированное ручное смешивание при контроле температуры и пропорций).
5. **Выдержка**, **демould**, контроль геометрии и сцепления плитки.

**КлинкерПрофи на сайте:** ППС **25 кг/м³**, плитка **245×65×6 мм**, панель **110×60×6 см**, **0,54 м²**, термозамки и **интегрированные крепления**.

## 6. Расчёт материалов (алгоритм для бота)

Всегда говорить: **ориентир**, финальную смету — **менеджер**. Округление **в большую сторону**.

### 6.1. Площадь и панели

```
S_gross — площадь стен под облицовку (м²)
S_open — проёмы (м²)
S = (S_gross - S_open) × (1 + k_waste)
```

**k_waste:** **0,05–0,07** (5–7 % на подрезку); сложный фасад — до **0,10**.

**КлинкерПрофи (каталог):** полезная площадь панели **A_panel = 0,54 м²**.

```
N_panels = ceil(S / 0,54)
S_order = N_panels × 0,54   (фактическая заказная площадь, м²)
```

### 6.2. Клей-пена

Ориентиры рынка (ровное основание, полосы по периметру + вертикали):

| Условие | Расход |
|---------|--------|
| **Стандарт** | **1 баллон 750 мл на 5–7 м²** фасада |
| **Ровное основание, экономный монтаж** | до **10–12 м² / баллон** (750 мл) — по инструкции производителя пены |
| **Неровности, холод** | **1 баллон на 4–5 м²** (+10–20 %) |

```
N_foam = ceil(S / 6)     — среднее, баллонов 750 мл
N_foam_rough = ceil(S / 5) — с запасом / ЛО
```

### 6.3. Дюбели / анкеры

| Норма | Значение |
|-------|----------|
| На **1 панель** | **6–8 шт.** (типично для панели ~0,5–0,7 м²) |
| На **1 м²** | **9–14 шт.** |

```
N_anchors = max(N_panels × 7, ceil(S × 10))
```
(7 шт/панель или 10 шт/м² — что больше; для **КлинкерПрофи** уточнять по инструкции к панели.)

### 6.4. Затирка швов клинкера

| Норма | Значение |
|-------|----------|
| **Стандарт** (шов ~8–12 мм, плитка ~245×65) | **2,5–3 кг / м²** |
| **Широкий шов / фактурная кладка** | **4–6 кг / м²** |
| **Запас на потери** | **+10–20 %** |

```
M_grout_kg = S_order × 2,8 × 1,15    (кг сухой смеси)
Bags_25kg = ceil(M_grout_kg / 25)
```

**Температура:** затирка **+5 °C** и выше (см. п. 3).

### 6.5. Пример (для проверки логики бота)

Дом: **S_gross = 120 м²**, проёмы **18 м²**, запас **7 %**.

- S = (120 − 18) × 1,07 ≈ **109,1 м²**
- N_panels = ceil(109,1 / 0,54) = **203 шт.**
- S_order = 203 × 0,54 ≈ **109,6 м²**
- Пена: ceil(109,6 / 6) ≈ **19** баллонов (750 мл); с запасом **22**
- Дюбели: max(203×7, 1096) = **1421** → округлить **1420–1430**
- Затирка: 109,6 × 2,8 × 1,15 ≈ **353 кг** → **15** мешков по 25 кг

### 6.6. Что спросить у клиента перед расчётом

- Площадь стен или **длина/ширина/высота** дома (простой прямоугольник).
- Количество и размер **окон/дверей**.
- **Основание** (газобетон, кирпич, каркас → обрешётка?).
- **Толщина** панели (60 / 80 / 100 мм).
