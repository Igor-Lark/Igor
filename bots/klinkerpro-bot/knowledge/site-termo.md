# Официальный сайт КлинкерПрофи — каталог термопанелей (https://marmara-pro.ru/termo)

Источник для консультанта. Страница только про **термопанели с клинкерной плиткой** и сопутствующие **строительные смеси** для монтажа. Не упоминать гибкий кирпич, гибкий камень, фасадную доску.

## Описание продукта

**Термопанели с клинкерной плиткой** — фасад «утепление + декоративная облицовка» в одной панели.

Состав:

- утеплитель: **пенополистирол 25 кг/м³**;
- лицо: **клинкерная плитка** (УФ-стойкость, мойка, долговечный внешний вид).
