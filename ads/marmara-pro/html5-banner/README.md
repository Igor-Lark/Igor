# HTML5-баннеры Яндекс Директ — термопанели КлинкерПрофи

Примеры анимированных HTML5-креативов для [marmara-pro.ru/termo](https://marmara-pro.ru/termo).

## Размеры

| Папка | Формат | Файл для загрузки |
|-------|--------|-------------------|
| `300x250/` | Medium Rectangle | `dist/klinkerpro-termo-300x250.zip` |
| `240x400/` | Vertical | `dist/klinkerpro-termo-240x400.zip` |

## Сборка ZIP

```bash
cd ads/marmara-pro/html5-banner
chmod +x build-zips.sh
./build-zips.sh
```

## Загрузка в Директ

1. Кампания → объявление → **HTML5-баннер** → загрузить ZIP из `dist/`.
2. **Ссылка на сайт:** `https://marmara-pro.ru/termo` (переход через `yandexHTML5BannerApi.getClickURLNum(1)`).
3. UTM для отчётов (опционально в поле ссылки кампании):  
   `utm_source=yandex_direct&utm_medium=html5&utm_campaign=termopaneli`

## Содержание креатива

- **Бренд:** КлинкерПрофи (логотип с сайта).
- **Визуал:** дом с фасадом термопанелей (`75_IZO_HOU_L3_MAX_03.png`), образец **Колорадо** из каталога.
- **Цены с сайта:** от **1 550 ₽/панель**, **2 500 ₽/м²**, **50+** фактур.
- **УТП:** срок службы от 20 лет, монтаж ~10 м²/сутки, гарантия до 5 лет, СПб и ЛО.
- **Анимация:** смена 3 слайдов, ~12–14 с цикл (≤ 30 с по требованиям Директа).
- **Маркировка:** «Реклама · КлинкерПрофи».

## Технические требования (Яндекс Директ)

- ZIP до **3 МБ**, не более **20** файлов, имена только лatinицей.
- В корне архива — `index.html`, ресурсы по **относительным** путям.
- Мета-тег размера: `<meta name="ad.size" content="width=...,height=...">`.
- Клик: `yandexHTML5BannerApi.getClickURLNum(1)`.
- Без внешних запросов, счётчиков и видео.

## Предпросмотр локально

Откройте `300x250/index.html` или `240x400/index.html` в браузере.  
Без API Директа клик ведёт на `/termo` с UTM (для теста).
