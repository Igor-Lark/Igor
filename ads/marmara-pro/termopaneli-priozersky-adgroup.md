## Инструкция: добавить группу в Яндекс Директ

### Вариант А — группа в существующей кампании «Термопанели»

1. Войти в [Яндекс Директ](https://direct.yandex.ru/) → кампания **Термопанели**.
2. **Добавить группу** → название: `Приозерский район`.
3. **Регион показа:** в настройках кампании убедиться, что выбрана Ленинградская область; для этой группы задать **корректировку ставок** только для Приозерского района (Настройки → Корректировки → Гео).
4. **Ключевые фразы:** Импорт → загрузить `termopaneli-priozersky-keywords.csv` или вставить вручную из таблиц выше.
5. **Объявления:** создать 5 объявлений по таблицам или импортировать из `termopaneli-priozersky-ads.csv`.
6. **Ссылка:** `https://marmara-pro.ru/termo` + UTM (см. выше).
7. **Минус-слова:** добавить списки из раздела «Минус-слова» на уровне кампании и группы.
8. **Ставки:** начальные 40–80 ₽ за клик (поиск, Ленобласть); через 1–2 недели оптимизировать по статистике.
9. **Модерация:** дождаться одобрения (обычно до 3 рабочих часов).

### Вариант Б — новая кампания только для Приозерского района

Если отдельной кампании «Термопанели» ещё нет:

1. **Создать кампанию** → «Реклама в Поиске» → «Мастер кампаний» или «Режим эксперта».
2. Название: `Термопанели — Marmara PRO`.
3. Регион: **Приозерский район, Ленинградская область** (можно расширить до всей области с понижением ставок вне района).
4. Создать одну группу **Приозерский район** и заполнить по этой спецификации.
5. Подключить **Яндекс Метрику** (счётчик на marmara-pro.ru), цели: «Отправка формы», «Клик по телефону».

### Проверка после запуска

- [Вордстат](https://wordstat.yandex.ru/) — частотность по «термопанели приозерск».
- [Метрика](https://metrika.yandex.ru/) — UTM `utm_content=priozersky`.
- Директ → **Поисковые запросы** — добавлять нерелевантные в минус-слова еженедельно.
